2. Funciones y datos que se guardan en el navegador

La biblioteca de preguntas y los juegos funcionan principalmente en el navegador. La aplicación puede guardar en el almacenamiento local del dispositivo, mediante la tecnología localStorage, preguntas que la persona marca como favoritas bajo la clave entredos-saved. Ese contenido permanece en el navegador hasta que se borre desde las opciones del propio sitio/navegador o se eliminen los datos del sitio.

La función de sala remota puede guardar bajo la clave entredos-online-session un código de sala, un token aleatorio de sesión y el rol de la persona para permitir reanudar la sala en ese navegador. No se trata de una cuenta de usuario permanente.

3. Datos tratados en la función online

Cuando una persona crea o se une a una sala, el navegador envía a la función remota de Cercora datos necesarios para prestar esa función: nombre o apodo (limitado por la aplicación), código de sala, tema, modo de juego, intensidad elegida, límite de preguntas, rol y token aleatorio. Al responder se envía el texto introducido en la respuesta (hasta 600 caracteres), asociado al código de sala y a la ronda correspondiente.

El servicio remoto utiliza Supabase, alojado en la región de la Unión Europea (eu-west-1, Irlanda). La función del servidor aplica límites de intentos y utiliza un hash HMAC de la dirección IP obtenida de la infraestructura de red para controlar abusos; no se guarda la dirección IP en claro en esa tabla de límites. Las respuestas se muestran a cada participante solo cuando ambos han respondido.

Las salas contienen una fecha de expiración y la aplicación deja de permitir el acceso cuando esa fecha ha pasado. No se ha verificado una política de borrado físico automático en la base de datos, por lo que no se promete un plazo concreto de eliminación. La duración efectiva de los registros debe confirmarse en la configuración de Supabase antes de publicar esta política como definitiva.

4. Proveedores y destinatarios

El sitio está alojado mediante GitHub Pages. La función online utiliza Supabase para almacenar temporalmente el estado de las salas, los nombres, las respuestas y los datos técnicos descritos arriba. Estos proveedores pueden tratar datos técnicos de conexión y seguridad conforme a sus propias políticas.

En la versión publicada de Cercora no se ha instalado el código de Google AdSense en la pantalla interactiva del juego. Tampoco se ha identificado una herramienta de analítica propia. Si se incorporan proveedores adicionales, esta política debe actualizarse antes de activar el tratamiento.

5. Finalidades y bases jurídicas

El almacenamiento local permite recordar preguntas guardadas y reanudar una sala en el mismo dispositivo. Los datos enviados a Supabase permiten crear, mantener y sincronizar una sala entre dos participantes. La base jurídica aplicable debe determinarse atendiendo a la configuración definitiva del servicio y a la relación con la persona usuaria; el responsable debe documentarla antes del lanzamiento.

6. Menores y datos sensibles

Cercora está concebida para conversaciones entre parejas y puede inducir a compartir información personal, íntima o sensible en las respuestas. No se debe introducir información sobre salud, vida sexual, orientación sexual, conflictos graves, terceros identificables u otros datos sensibles que no sean necesarios. El servicio no está diseñado para recoger deliberadamente datos de menores; el responsable debe definir y publicar su criterio de edad y medidas aplicables antes del lanzamiento.

7. Derechos

La persona usuaria puede tener derechos de acceso, rectificación, supresión, limitación, oposición y portabilidad, y retirar un consentimiento cuando el tratamiento se base en él.
